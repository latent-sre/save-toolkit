**P3 — AUDIT-AUTHORING-001: workspace projection corrupts Claude-specific delegation examples.** [verified] The canonical [Claude reference](../../../../skills/agent-authoring/references/claude-code-frontmatter.md), lines 41–44, requires full plugin-qualified targets and explicitly says bare targets did not match on tested hosts. [verified] Trigger: a workspace Copilot author follows the linked platform reference when creating canonical Claude delegation grants. The [generator](../../../../scripts/generate_platform_adapters.py), lines 302–305 and 497–505, removes namespaces from every adapted Markdown resource, including examples discussing the other platform. The impact is incorrect authoring guidance and avoidable validation failure or a nonmatching grant when reused elsewhere. This is a high-confidence text/transform defect; no agent copied it and no live dispatch failure was observed. Counterevidence limits severity: canonical examples remain correct; installed Agent Plugins use canonical `skills/`; the fleet's target parser and validator reject unqualified canonical grants. Smallest repair: preserve literal Claude-specific examples while adapting actual invocation instructions, with a regression covering this cross-platform reference. A blanket ban on namespaced text in workspace resources would preserve the defect.
